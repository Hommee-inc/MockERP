# v0.5 — Module integration

This version checks whether the commercial, inventory, and finance modules form
one system rather than three isolated tables.

## Cross-module checks

- every confirmed sale has an inventory exit and an account receivable;
- every completed return has an inventory entry and a refund;
- sale, stock, and finance values agree within the rounding tolerance;
- all relationships point to existing source records.

Build a small golden dataset and run these checks across the whole chain. This
dataset becomes the baseline for the controlled errors introduced in v0.6.

## Portfolio angle

“Added end-to-end reconciliation so one sale can be followed through the
commercial, inventory, and financial modules.”
