# v1.0 — Databricks Bronze

Move the generated Parquet data into Databricks and preserve it as the raw
layer.

## Planned work

1. upload the v0.6 files to a validated storage location;
2. read them with Spark;
3. add ingestion timestamp and source-file metadata;
4. write one Delta table per entity;
5. keep the data unchanged, including the known anomalies.

The Bronze layer is about traceability, not cleanup. Cleaning belongs in Silver.

## Platform note

Catalogs, schemas, Volumes, persistence, and the available compute must be
validated in Databricks Free Edition before this version is described as
complete.
