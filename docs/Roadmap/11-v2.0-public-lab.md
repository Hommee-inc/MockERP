# v2.0 — Public lab

Turn MockERP from a personal project into a small reusable practice lab.

## Public-facing deliverables

- a README that explains the domain and setup;
- documented dataset scenarios and anomaly recipes;
- a clear entity and relationship reference;
- a dashboard covering commercial, inventory, finance, reconciliation, and
  data quality;
- contribution guidance for new modules and anomalies.

Configuration should eventually live in YAML or another documented format so a
new user can choose data volume and anomaly recipes without editing generator
code.

## Definition of done

Someone unfamiliar with the repository should be able to generate a scenario,
follow its relationships, run a quality exercise, and understand the expected
answer from the documentation alone.
