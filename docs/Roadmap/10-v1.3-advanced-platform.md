# v1.3 — Incremental platform

Make the Databricks pipeline behave more like a production workflow.

## Planned work

- replace batch file reads with Auto Loader where available;
- test schema evolution with a new field;
- use `MERGE` for idempotent upserts;
- preserve customer history with SCD Type 2;
- orchestrate generation, Bronze, Silver, and Gold as a Job;
- document a failed run and its recovery.

Each feature should be validated independently before being added to the full
pipeline. Databricks Free Edition limitations must be recorded alongside the
implementation.
