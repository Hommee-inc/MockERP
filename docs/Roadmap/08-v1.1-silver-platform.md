# v1.1 — Databricks Silver

Turn the raw Bronze data into validated, usable tables.

## Planned work

- apply explicit data types and basic normalization;
- deduplicate records using their business and technical keys;
- validate foreign keys and business invariants;
- send invalid records to quarantine tables;
- publish only records that pass the Silver checks.

Compare the quarantine counts with the anomaly manifest from v0.6. The point is
not simply to remove bad rows; it is to show that the expected issues were
detected without creating unnecessary false positives.
