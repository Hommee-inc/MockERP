# MERP v2.0 — Laboratório Público

## Objetivo da versão

Transformar o MERP de projeto pessoal em recurso reutilizável por outras pessoas: documentação completa, dashboard final e uma estrutura clara para quem quiser gerar seus próprios cenários.

## Escopo

### Dashboard final

```
Executive Overview
  Revenue, Orders, Customers, Average Ticket, Outstanding Receivables

Comercial
  Orçamento → Venda → Devolução, taxas de conversão e devolução

Estoque
  Posição de estoque, movimentações, divergências

Financeiro
  Contas a receber, pagamentos, inadimplência

Reconciliação
  MATCH / MISMATCH ao longo da cadeia orçamento-venda-estoque-financeiro

Data Quality
  Quality score, anomalias detectadas por tipo, taxa de detecção
```

### Documentação para uso externo

```
README.md
  - O que é o MERP
  - Como gerar seu próprio dataset (parâmetros de volume e anomalias)
  - Como configurar cenários de erro controlado
  - Estrutura de dados completa (todas as entidades e relacionamentos)
  - Sugestões de exercícios (pipelines, consultas, dashboards)

CONTRIBUTING.md
  - Como propor novos módulos ou novas anomalias
```

### Empacotamento

- Configuração via YAML documentada, permitindo que qualquer pessoa gere seu próprio volume e seu próprio conjunto de anomalias sem tocar em código
- Exemplos prontos de "receitas" de cenário (ex: "cenário focado em divergência financeira", "cenário focado em integridade de estoque")

## Critério de pronto

- Repositório público, com README que permite a alguém de fora rodar o gerador e reproduzir um cenário em poucos passos
- Dashboard publicado e acessível
- Pelo menos três "receitas" de cenário documentadas como ponto de partida para outras pessoas

## Ângulo do post

MERP v2.0: o projeto vira laboratório. Qualquer pessoa estudando engenharia de dados, análise de dados ou BI pode gerar seu próprio ambiente MERP, com seus próprios erros controlados, e praticar em cima de um cenário que se parece de verdade com um ERP real.
