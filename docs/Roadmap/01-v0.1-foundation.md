# v0.1 — Registration foundation

This is the first usable slice of MockERP: shared registrations and the first
customer generator.

## Goal

Create reusable Brazilian registration data for individuals and legal entities,
then build a customer record from that shared base without duplicating common
fields.

## Rules

- every entity has a stable internal ID;
- individuals use CPF and legal entities use CNPJ;
- clean runs keep business identifiers unique;
- contacts and addresses belong to the base entity;
- customer-specific fields are added by the customer generator;
- providers produce values, while generators decide the record shape;
- the same seed reproduces the same entity.

## Validation

Tests cover the entity schema, address structure, CPF/CNPJ uniqueness,
configuration validation, provider contracts, and reproducibility.

This foundation is the source for the commercial flow planned in v0.2.

## Portfolio angle

“Built the registration foundation of a synthetic ERP using provider contracts,
dependency injection, stable identifiers, and reproducible Brazilian entity
data.”
