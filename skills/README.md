# MockERP Project Skills

These skills are exclusive to the MockERP repository. They encode the
project's architecture, entity-generation SOT, and Databricks Free Edition
constraints.

## Available skills

- `mockerp-databricks-architecture`: choose the correct layer and validate
  platform assumptions.
- `mockerp-entity-generation`: implement providers, helpers, models, and
  domain generators according to the entity-generation SOT.
- `mockerp-databricks-validation`: validate package code, relationships,
  reproducibility, and Databricks-compatible execution boundaries.

Read the relevant skill before making a change in its area. All skill content
and all project output must be written in English.
